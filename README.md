🤖 Assistente de Atendimento com Inteligência Artificial

Projeto de portfólio desenvolvido por Stefani Neves, estudante de Ciência da Computação, com o objetivo de demonstrar a aplicação de Inteligência Artificial na construção de soluções de atendimento.

Sobre o projeto

O Assistente de Atendimento com IA é uma aplicação web desenvolvida em Python que utiliza uma base de conhecimento (FAQ) e um modelo de linguagem para elaborar respostas às dúvidas dos usuários.

Tecnologias utilizadas

- Python
- Flask
- OpenAI API
- JSON
- Prompt Engineering
- Git e GitHub

Funcionalidades

- Interface para envio de perguntas.
- Consulta a uma base de conhecimento.
- Recuperação de informações relevantes.
- Geração de respostas utilizando IA.
- Tratamento de falhas de comunicação com a API.
- Orientação para atendimento humano quando necessário.

Como executar

1. Pré-requisitos

- Python 3.10 ou superior.
- Uma chave de API da OpenAI.

2. Instalação

Clone o repositório e instale as dependências:

pip install -r requirements.txt

3. Configuração

Crie um arquivo ".env" com suas próprias credenciais:

OPENAI_API_KEY=sua_chave
OPENAI_MODEL=gpt-4o-mini

Nunca compartilhe sua chave de API.

4. Execução

python app.py

Acesse no navegador:

http://127.0.0.1:5000
