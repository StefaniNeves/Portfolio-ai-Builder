Portfólio de Inteligência Artificial e Automação

Stefani Neves | Ciência da Computação

Bem-vindo(a) ao meu portfólio de projetos voltados ao desenvolvimento de soluções com Inteligência Artificial, automação de processos, integração de APIs e tecnologia aplicada a negócios.

Este repositório reúne projetos práticos que demonstram minha evolução na construção de aplicações inteligentes, desde assistentes de atendimento até fluxos automatizados e ferramentas de análise de negócios.

Meu objetivo é desenvolver soluções que utilizem tecnologia para resolver problemas reais, otimizar processos e apoiar decisões.

03. AI Business Manager

<text color="success" weight="semibold" size="xs">PROJETO 03</text>

Objetivo: desenvolver uma solução de análise comercial que transforma registros de vendas em indicadores e recomendações para apoiar decisões de negócio.

Funcionalidades

- Análise de dados comerciais.
- Cálculo de faturamento e indicadores de vendas.
- Identificação de produtos com maior faturamento.
- Análise de resultados por categoria.
- API REST para processamento de informações.
- Dashboard interativo para visualização dos resultados.
- Modo demonstração independente de chaves externas.
- Arquitetura com adaptadores para diferentes provedores de IA.
- Fluxo de automação disponibilizado para importação no n8n.
- Testes automatizados.

Tecnologias

- Python
- FastAPI
- Streamlit
- Pandas
- Pydantic
- Pytest
- OpenAI
- Anthropic
- Google Gemini
- n8n
- Docker
- GitHub Actions

Competências demonstradas: desenvolvimento de aplicações com IA, análise de dados, arquitetura modular, orquestração de provedores, construção de APIs e aplicação de tecnologia em processos de negócio.

Minha abordagem de desenvolvimento

Busco desenvolver projetos considerando não apenas a implementação do código, mas também a organização da solução e sua aplicação prática.

Durante o desenvolvimento, valorizo:

- Identificação do problema que a solução pretende resolver.
- Escolha de tecnologias adequadas ao objetivo.
- Separação de responsabilidades e organização modular.
- Integração entre ferramentas e serviços.
- Criação de instruções claras para modelos de IA.
- Testes e validação das funcionalidades.
- Documentação para facilitar a compreensão e avaliação técnica.
- Evolução contínua das soluções.
