Projetos de Inteligência Artificial e Automação

Este repositório reúne dois projetos desenvolvidos com foco em Inteligência Artificial, desenvolvimento de aplicações, integração de APIs e automação de processos.

Os projetos têm como objetivo demonstrar aplicações práticas de IA na resolução de problemas, otimização de tarefas e melhoria de processos.

🚀 Projetos

01. Assistente de Atendimento com Inteligência Artificial

Tecnologias: Python, Flask, OpenAI API, HTML, CSS e JSON.

Aplicação desenvolvida para simular um assistente virtual capaz de responder às dúvidas dos usuários utilizando Inteligência Artificial e informações previamente estruturadas.

Principais funcionalidades:

- Interface para interação com o usuário.
- Integração com a API da OpenAI.
- Processamento de perguntas e geração de respostas.
- Utilização de informações armazenadas em arquivo JSON.
- Organização do código em módulos.
- Testes automatizados.

Objetivo: demonstrar conhecimentos em Python, desenvolvimento web, integração com APIs e engenharia de prompts.

02. Automação de Triagem de Solicitações com IA

Tecnologias: n8n, Webhook, HTTP Request, OpenAI API e JSON.

Projeto de automação desenvolvido para demonstrar como a Inteligência Artificial pode auxiliar na análise e organização de solicitações recebidas por uma empresa.

Principais funcionalidades propostas:

- Recebimento de solicitações por Webhook.
- Organização e validação dos dados recebidos.
- Integração com a API de Inteligência Artificial.
- Classificação de solicitações por categoria e prioridade.
- Geração de resumos e recomendações.
- Retorno de informações estruturadas em JSON.

Objetivo: demonstrar conhecimentos em automação de processos, integração entre sistemas, APIs e utilização de IA em fluxos de trabalho.

🛠️ Competências desenvolvidas

- Python e programação.

- Engenharia de prompts.
