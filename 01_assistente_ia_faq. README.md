Assistente de Atendimento com Inteligência Artificial

Sobre o projeto

Este projeto consiste em um protótipo de assistente virtual desenvolvido em Python, integrado a um modelo de inteligência artificial para responder perguntas de usuários.

O sistema utiliza uma base de perguntas frequentes (FAQ) para recuperar informações relevantes e gerar respostas em linguagem natural.

Tecnologias utilizadas

- Python
- Flask
- OpenAI API
- JSON
- Engenharia de prompts

Funcionalidades

- Recebimento de perguntas dos usuários.
- Busca de informações em uma base de conhecimento.
- Integração com modelo de linguagem.
- Geração de respostas em português.
- Orientação para atendimento humano quando não há informações suficientes.

Objetivo

Demonstrar a aplicação de inteligência artificial na construção de soluções de atendimento, integração de APIs e desenvolvimento de aplicações.

Próximas melhorias

- Implementação de testes automatizados.
- Melhorias na recuperação de informações.
- Integração com banco de dados.
- Implantação online.
