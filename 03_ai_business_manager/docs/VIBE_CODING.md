# Vibe coding evidence guide (Cursor)

The project does not claim that Cursor was used to generate code. To demonstrate this skill
truthfully, use Cursor for one bounded improvement, for example adding date-range filtering to
the dashboard.

Document:
- the exact task/prompt given to Cursor;
- files it proposed changing;
- what you accepted, rejected, or corrected;
- tests you ran after the change;
- a short reflection on limitations and human review.

Commit the improvement and add a short entry to `docs/WORK_LOG.md`. Do not claim tool usage
that did not occur.
