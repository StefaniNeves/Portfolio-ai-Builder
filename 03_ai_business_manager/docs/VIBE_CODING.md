# Registro de uso de Vibe Coding (Cursor)

Este projeto não afirma que o Cursor foi utilizado para gerar o código. Para demonstrar essa habilidade de forma transparente, utilize o Cursor em uma melhoria específica e de escopo limitado. Um exemplo seria adicionar um filtro por período ao dashboard.

Registre:
- a tarefa e o prompt exatos enviados ao Cursor;
- quais arquivos a ferramenta sugeriu alterar;
- o que você aceitou, rejeitou ou corrigiu;
- quais testes executou depois da alteração;
- uma breve avaliação das limitações encontradas e da revisão humana realizada.

Faça um commit com a melhoria e adicione um registro ao arquivo `docs/WORK_LOG.md`. Não declare o uso de ferramentas ou etapas que não tenham sido realmente realizadas.
